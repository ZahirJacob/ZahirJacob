## Featured projects

**[multi-source-rag-assistant](https://github.com/ZahirJacob/multi-source-rag-assistant)** · NLP
A conversational assistant that answers questions over three heterogeneous sources — documents, tabular data and a knowledge graph — using hybrid retrieval (semantic + BM25 + cross-encoder re-ranking), a local LLM that writes JSON filters and Cypher queries, conversational memory and a ReAct agent with tools. Runs entirely on local models.

**[australia-rain-prediction](https://github.com/ZahirJacob/australia-rain-prediction)** → **[australia-rain-app](https://github.com/ZahirJacob/australia-rain-app)** · Machine learning
Next-day rain classifier trained on ten years of Australian weather observations: 23 candidate configurations compared with stratified cross-validation, temporal evaluation and Docker inference. Then deployed as a [live web app](https://australia-rain-app.onrender.com) that fetches today's weather for any of 49 stations and runs the neural network in pure NumPy — no TensorFlow, no API key.

**[activcelu](https://github.com/ZahirJacob/activcelu)** · Web
Website for a phone-repair business in Rosario, built and delivered for a real client.
